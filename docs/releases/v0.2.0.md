**v0.2.0 · Tahap 2: Auth dan toko · 2026-10-11**

Tahap 2 membuka pintu masuk aplikasi:
- Pembeli bisa login dengan Google di web.
- Penjual bisa mendaftar dan login dari Android, membuka toko dengan pin lokasi dan rekening, lalu mengatur metode pengiriman.
- Admin memverifikasi toko dan mengelola kategori hasil laut di panel Filament.
- Super Admin bisa melihat siapa mengubah apa lewat activity log.

Kode juga kembali memakai struktur direktori bawaan Laravel.

## Sorotan

- **Satu Action untuk dua pintu login Google.** `LoginWithGoogle` dipakai oleh login web (Socialite) maupun API (Google ID token yang diverifikasi lewat `tokeninfo`). Hasilnya sama: satu email menjadi satu user, dan akun sosial ditautkan ke user yang sudah ada.
- **API Android dengan token Sanctum** di `/api/v1`. Responsnya selalu JSON, walaupun request dikirim tanpa header `Accept`. Semua endpoint auth publik diberi rate limit: login 5 per menit per email + IP, sedangkan register dan Google 10 per menit per IP.
- **Verifikasi toko yang aman dari balapan.** Transisi status ditulis di `StoreStatus::canTransitionTo()`. Keempat Action admin memakai `ChangeStoreStatus`, yang mengunci baris toko lebih dulu, sehingga dua admin tidak bisa mengubah toko yang sama bersamaan.
- **Panel `/seller` dengan tenancy per toko.** Hanya anggota toko `active` yang bisa masuk, dan akses dicek ulang di setiap request. Toko yang ditangguhkan langsung terkunci.
- **Kategori bertingkat dengan pewarisan atribut.** Rantai leluhur dibaca lewat recursive CTE PostgreSQL dalam satu query. API pohon kategori memuat semuanya dengan dua query, berapa pun jumlah kategorinya.
- **Activity log tanpa data sensitif.** Perubahan toko dan kategori tercatat bersama pelakunya, tetapi nomor rekening tidak pernah masuk log.
- **Pengaman database.** Claude Code diblokir menjalankan `migrate:fresh`, `migrate:rollback`, `migrate:reset`, `migrate:refresh`, dan `db:wipe` di repo ini. Di production, perintah-perintah itu ditolak walaupun memakai `--force`.

## Perubahan yang perlu diketahui

- **Struktur kode** pindah dari `app/Domain/<Area>/...` ke direktori bawaan Laravel (`app/Models`, `app/Actions`, `app/Data`, `app/Enums`, `app/Exceptions`, `app/Policies`). Generator, tebakan factory, dan auto-discovery Policy sekarang bekerja tanpa konfigurasi tambahan.
- **Package baru** (semua sudah disetujui sejak perencanaan): `laravel/sanctum`, `filament/filament` v5, `spatie/laravel-permission`, `bezhansalleh/filament-shield`, `laravel/socialite`, `spatie/laravel-activitylog` v5. Constraint PHP dinaikkan ke `^8.4`.
- **Variabel `.env` baru:**
  - `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`, `GOOGLE_ALLOWED_CLIENT_IDS` untuk login Google;
  - `DEMO_PASSWORD` untuk akun demo.
- **Data demo:** `php artisan db:seed` mengisi role, kategori hasil laut, akun `superadmin@seafood.test` dan `admin@seafood.test`, serta tiga toko contoh. Seeder akun dan toko demo dilewati di production.
