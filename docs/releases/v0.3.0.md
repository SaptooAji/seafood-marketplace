**v0.3.0 · Tahap 3: Produk · 2026-10-14**

Tahap 3 mengisi marketplace dengan barang dagangan:
- Penjual mengelola produk, varian, dan foto, mencatat buku stok, dan mengonfirmasi stok setiap pagi, baik dari panel `/seller` maupun API untuk Android.
- Admin memblokir dan membuka blokir produk beserta alasannya.
- Pembeli bisa menjelajah katalog web, mencari toko terdekat, dan membuka halaman produk serta halaman toko. Semua halaman publik siap untuk mesin pencari.
- Penjual bisa meminta saran deskripsi produk dari AI (Google Gemini).

Tahap ini ditutup dengan audit keamanan Tahap 1–3 terhadap `docs/security-standards.md`. Temuannya yang berprioritas tinggi dan sedang sudah diperbaiki sebelum rilis ini.

## Sorotan

- **Stok hanya berubah lewat satu pintu.** `RecordStockMovement` mengubah stok dengan satu `UPDATE` bersyarat di PostgreSQL. Hitungannya desimal tepat, baris terkunci selama perubahan, dan stok tidak bisa turun di bawah nol walaupun ada dua permintaan bersamaan. Setiap perubahan tercatat di buku stok (`stock_movements`) beserta pelakunya.
- **Konfirmasi "Stok hari ini".** Penjual menghitung stok setiap pagi dan mengonfirmasinya sekaligus. Varian yang stoknya belum dikonfirmasi lebih dari 24 jam diberi tanda "stok belum dikonfirmasi" di halaman pembeli.
- **Atribut kategori divalidasi.** `SaveProduct` mencocokkan nilai atribut produk dengan atribut yang diwarisi kategorinya (tipe, pilihan, wajib), sehingga data produk tetap seragam per jenis hasil laut.
- **Foto produk diproses ulang.** Setiap upload di-decode dan disimpan ulang sebagai WebP, dengan sisi terpanjang 1600 px dan thumbnail 400 px. Satu produk boleh punya paling banyak 8 foto, masing-masing maksimal 5 MB. Proses ulang ini juga membuang metadata EXIF, termasuk lokasi kamera.
- **Toko terdekat tanpa ekstensi database.** Jarak dihitung dengan rumus haversine di query PostgreSQL. Lokasi pembeli dibulatkan ke 3 desimal (sekitar 100 m) dan tidak disimpan di database, sesi, maupun cookie.
- **Katalog dengan filter di URL.** Komponen Livewire `Catalog` menyimpan pencarian, filter kategori, kondisi, toko, rentang harga, radius, dan urutan di query string, sehingga hasil filter bisa dibagikan.
- **SEO halaman publik.** Halaman publik punya meta description (`seo_description`), Open Graph, dan JSON-LD. Situs juga punya `sitemap.xml` dan `robots.txt`. JSON-LD di-encode dengan flag `JSON_HEX_*`, sehingga teks penjual tidak bisa keluar dari tag `<script>`.
- **Saran deskripsi dengan AI yang dibatasi.** `SuggestProductDescription` memanggil Gemini dengan:
  - batas harian untuk seluruh platform;
  - satu kali coba ulang ke model cadangan saat model utama penuh (503);
  - log pemakaian di channel `ai_usage` tanpa isi prompt.

  Fitur ini mati kalau `GEMINI_API_KEY` kosong, dan toko yang ditangguhkan tidak bisa memakainya.
- **Audit keamanan sebelum rilis.**
  - `docs/security-standards.md` memberi setiap aturan kode (`AC-7`, `RATE-3`, ...) dan status yang dibuktikan dengan test.
  - Audit menutup aturan ⚠️ dengan test baru dan memperbaiki temuannya:
    - toko yang ditangguhkan sekarang ditolak di seluruh API penjual, tidak hanya di panel;
    - token API berlaku 90 hari dan memakai prefix `sfm_`;
    - API dibatasi 60 permintaan per menit per pengguna;
    - upload foto dibatasi 10 per menit per pengguna dan 200 per hari per toko.
  - Secret scanning, push protection, `composer audit`, dan Dependabot sudah aktif.

## Perubahan yang perlu diketahui

- **Package baru** (disetujui di issue masing-masing):
  - `intervention/image` ^4 untuk memproses foto;
  - `livewire/livewire` ^4, yang sebelumnya hanya ikut lewat Filament, sekarang dideklarasikan langsung karena dipakai web pembeli.
- **Migrasi baru:** `products`, `product_variants`, `product_images`, `product_attribute_values`, `stock_movements`, serta kolom `seo_description` di `products`.
- **Variabel `.env` baru:**
  - `SESSION_SECURE_COOKIE`, wajib `true` di production;
  - `SANCTUM_EXPIRATION` (menit, default 90 hari) dan `SANCTUM_TOKEN_PREFIX` (default `sfm_`);
  - `GEMINI_API_KEY`, `GEMINI_FALLBACK_MODELS`, `GEMINI_DAILY_LIMIT` untuk saran deskripsi AI (opsional).
- **Setup lokal:** jalankan `php artisan storage:link` agar foto produk tampil.
- **Token API sekarang kedaluwarsa.** Token yang dibuat sebelum rilis ini juga berakhir 90 hari setelah dibuat. Aplikasi Android (Tahap 4) harus mengarahkan penjual ke layar login saat menerima 401. Token kedaluwarsa dihapus harian oleh `sanctum:prune-expired`, sehingga server production butuh cron `php artisan schedule:run` setiap menit.
- **Rate limit baru:**
  - semua route API yang butuh login dibatasi 60 permintaan per menit per pengguna;
  - upload foto dibatasi 10 per menit per pengguna dan 200 per hari per toko.

  Melewati batas menghasilkan 429 dengan `Retry-After`.
- **Toko `suspended`** ditolak dengan 403 di semua endpoint API penjual, kecuali `GET /seller/store` dan `POST /seller/store`.
- **`composer test` dan `composer check`** sekarang menjalankan Pest secara paralel.
- **Data demo:** `php artisan db:seed` sekarang juga mengisi produk, varian, dan stok untuk toko contoh.
